# 🏛️ Distortionz Cityhall

**Distortionz Cityhall** is a FiveM/Qbox city hall resource built for immersive government and civilian roleplay. Players can access city services, manage identification, apply for jobs, handle licenses, and interact with city hall staff through a clean configurable system.

## ✨ Features

- 🏛️ City hall service system
- 🪪 ID card support
- 💼 Job center support
- 📄 License service support
- 🧍 NPC clerk interaction
- 🎯 `ox_target` interaction support
- 🔔 `ox_lib` notification support
- 📦 `ox_inventory` item support
- 🗺️ Configurable blip/location
- ⚙️ Easy configuration through `config.lua`
- 🧼 Clean and simple resource structure

## 📦 Dependencies

- `ox_lib`
- `ox_target`
- `ox_inventory`
- `qbx_core` or `qb-core`

Optional:

- `oxmysql`
